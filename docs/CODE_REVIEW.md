# Code Review Checklist

Use this checklist when reviewing or responding to pull request comments.

For each review comment:

- ✅ **Agree?** → Make the change and resolve
- ❌ **Disagree?** → Reply with reasoning and reference to our guidelines
- ❓ **Unclear?** → Ask clarifying questions
- 📌 **Already done?** → Reference the commit and resolve

All comments must be resolved or responded to.
